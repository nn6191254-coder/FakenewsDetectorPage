DETECTION PIPELINE

How Authentiq AI Analyzes Articles

01

Input Normalization

Text is stripped of URLs, anomalous characters, and excessive whitespace while preserving semantic punctuation and financial markers.

02

TF-IDF Vectorization

N-gram feature extraction (1-word and 2-word combinations) with sublinear term-frequency weighting captures contextual phrasing.

03

ML Probability

A balanced Logistic Regression classifier computes the core statistical likelihood of credible vs misleading language.

04

Linguistic Heuristics

Multi-signal analyzers inspect source attribution, clickbait triggers, emotional bias, fraud vectors, and writing stylometry.

MACHINE LEARNING ARCHITECTURE

Model Design & Explainability

Explainable Hybrid Architecture

Authentiq AI combines statistical Machine Learning with rule-based linguistic verification to deliver transparent, explainable predictions rather than opaque black-box verdicts.

Feature Vector Representation

The system utilizes scikit-learn's TfidfVectorizer configured with unigram and bigram ranges (ngram_range=(1,2)) and sublinear scaling. This allows the model to distinguish between genuine investigative phrasing ("official reported that") and sensational clickbait tropes ("you will never believe").

Multi-Signal Verification

In addition to ML classification, the engine performs active heuristic checks across 6 critical dimensions: Citation Attribution, Sensationalism Detection, Affective Manipulation, Conspiracy Signatures, Advance-Fee/Phishing Vectors, and Stylometric Quality.

PROJECT INFORMATION

Authentiq AI Architecture & Stack

Authentiq AI is a full-stack fake news, disinformation, and fraud detection dashboard engineered with modern web technologies:

  • Backend Framework: Python Flask REST API
  • Machine Learning: Scikit-Learn (TF-IDF Vectorizer + Logistic Regression)
  • Database: SQLite with ISO 8601 audit history logging
  • Frontend: Responsive HTML5, Modern CSS Variables, Asynchronous JavaScript
